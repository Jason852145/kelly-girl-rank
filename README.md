# 可莉女孩即時排名（應援榜 + 人氣投票）

在 17LIVE（17.live）頁面一鍵叫出「可莉女孩應援榜」40 位參賽者的即時票數排名、每日變化與積分。

活動期間：10/1–10/13

## 即時排名網頁（`index.html`）

開啟 GitHub Pages 網址即可，不用安裝，手機也能看。

- 三個分頁：**總積分**、**應援榜**、**人氣投票**
- 總積分 = 應援榜積分 + 人氣投票積分（兩榜都是第 1 名 50 分 … 第 40 名 1 分），標出前 20 名晉級線
- 每 30 秒自動更新，切到其他分頁時暫停
- 上方關注卡片：總排名、是否在晉級線內、距第 20 名差幾分，以及兩個榜各自「再幾票可升一名、多幾分」
- 點任一列可換關注對象；網址加上 `#號碼`（例如 `#28`）可直接分享指定參賽者

### 資料來源

| 榜 | API | 名次怎麼算 |
|---|---|---|
| 應援榜 | `fireant.17app.co/api/v1/public/containers/{id}/summary` 的 `total` | 依票數排序，同票暫以號碼小者在前 |
| 人氣投票 | `cheerleaders.17.live/api/public/rank/snapshot?eventId=6&top=40` | 直接採用官方 `rank`（同票時較早達到者在前）；`candidateId` = 110 + 號碼 |

總積分同分時並列同名次。以上為非官方試算，結果以 17LIVE 公告為準。

## 書籤版（`bookmarklet.html`）

打開 `bookmarklet.html`，二選一：

- **方法 A**：把「應援榜排名」按鈕拖曳到 Chrome 書籤列
- **方法 B**：按「複製書籤程式碼」，在書籤列右鍵 →「新增網頁」，網址欄貼上

只支援電腦版瀏覽器；手機瀏覽器大多無法執行書籤程式。

## 使用

1. 到 17.live 任一頁面，點書籤
2. 右上角跳出排名面板，依票數由高到低排序
3. 點任一列可設為關注對象（預設 28 號），會標黃並顯示距上一名差幾票
4. 「匯出歷史 CSV」下載每日票數紀錄

## 運作方式

- 對 40 個參賽者各打一次 `https://fireant.17app.co/api/v1/public/containers/{id}/summary`，取回 `total` 當票數
- 每次開啟都把當下票數存成「今天（台北時間）」的快照，存在瀏覽器 `localStorage`
- 「較前日」= 今天這次讀到的票數 − 前一個有快照日期的**最後一次**快照
- 「積分」欄依名次對應固定分數：50, 47, 44, 41, 38, 35, 33, 31, 29, 27, 25, 24 … 1

## 已知限制

- **每日變化不是固定時間點的比較。** 快照是「當天最後一次打開時」的數字，所以「較前日」會因為你昨天幾點打開而不同。要比較公平，每天固定同一時間打開一次。
- **同票同分時名次不並列。** 票數相同時以號碼小的排前面，積分也照位置給，不一定符合官方計分規則。
- **API 欄位變動時會安靜地顯示 0 票。** 程式在找不到 `total` 時當作 0，不會報錯。
- **快照只存在本機瀏覽器。** 換電腦、換瀏覽器、清除網站資料，歷史就沒了；而且要固定在 17.live 網域點，因為 `localStorage` 分網域存。
- 參賽者 ID、名稱、積分表都寫死在程式裡，只適用這一次活動。

## 開發

- `src/bookmarklet.js`：可讀版原始碼
- `build.py`：把原始碼壓縮後寫回 `bookmarklet.html` 的書籤連結

```bash
python3 build.py
```
